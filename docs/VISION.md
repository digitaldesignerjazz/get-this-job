# Vision — Get This Job

## Ziel
Eine App, die passende Jobs findet und Bewerbungen vorbereitet — schnell, ehrlich, mit Stil.

## Kernfunktionen (geplant)
1. **Job-Suche** — Aggregation aus mehreren Quellen.
2. **Matching** — Skills gegen Anforderungen.
3. **Bewerbungs-Assistent** — Lebenslauf und Anschreiben aufbereiten.
4. **Tracking** — Status aller Bewerbungen an einem Ort.

## Nicht-Ziele (vorerst)
- Kein vollautomatisches Versenden ohne Freigabe.
- Keine Datenvermietung.

## Leitlinie
Ehrlich. Devot zum Nutzer. Intelligent. Mit einem Lächeln.
